# Kernel Image (vmlinux / image.ub)

## Description
The kernel image contains the Linux kernel with ZCU102-specific drivers and configurations. It's loaded by the bootloader and initializes the system hardware.

## File Details
- **File Formats**:
  - `vmlinux`: Raw ELF (development builds)
  - `image.ub`: FIT image (production builds)
- **Type**: Executable and Linkable Format (ELF) / Flattened Image Tree (FIT)
- **Generated By**: Yocto / PetaLinux build system
- **Location**: `/boot/` on target filesystem

## Versioning
- Follows Linux kernel versioning (e.g., `6.1.45`)
- Development builds include `-rc` suffix
- Custom patches appended with `-customN`

## Configuration
- **Defconfig**: `xilinx_zynqmp_defconfig`
- **Key Features**:
  - PREEMPT_RT patches (production)
  - Debug symbols (development)
  - Module signing (production)
  - KASLR enabled

## Dependencies
- Requires compatible bootloader version
- Matches device tree binary
- Module dependencies resolved at build time

## Verification
```bash
# Verify kernel version
uname -a

# Check loaded modules
lsmod

# Verify kernel config
zcat /proc/config.gz | grep CONFIG_DEBUG_KERNEL
```

## Performance
- Boot time target: < 5s to userspace
- Memory footprint: ~50MB (compressed)
- Supports SMP for all 4x Cortex-A53 cores

## Security
- Kernel ASLR enabled
- Module signing enforced in production
- Stack protection enabled
- SELinux/AppArmor support compiled in
