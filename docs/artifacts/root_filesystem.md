# Root Filesystem (rootfs.tar.gz / rootfs-dev.tar.gz)

## Description
The root filesystem contains the complete Linux system, including all binaries, libraries, and configuration files required for operation.

## File Details
- **Format**:
  - Production: Compressed tarball (`.tar.gz`)
  - Development: May include debug symbols and tools
- **Size**: 
  - Minimal: ~100MB (compressed), 300MB (uncompressed)
  - Full: ~300MB (compressed), 1.2GB (uncompressed)
- **Generated By**: Yocto / PetaLinux / Buildroot
- **Location**: Extracted to root (`/`) on target

## Contents
```
/
├── bin/           # Essential user binaries
├── boot/          # Bootloader and kernel images
├── etc/           # System configuration
├── home/          # User directories
├── lib/           # Shared libraries
├── opt/           # Optional software
├── sbin/          # System binaries
├── tmp/           # Temporary files
├── usr/           # User programs and data
└── var/           # Variable data
```

## Versioning
- Production: Semantic versioning (`MAJOR.MINOR.PATCH`)
- Development: Timestamp or build number
- Security updates: Appended with security bulletin ID

## Customization
### Common Customizations
- **Network Configuration**: `/etc/network/interfaces`
- **Users and Groups**: `/etc/passwd`, `/etc/group`
- **Startup Scripts**: `/etc/init.d/`, `/etc/rc.local`
- **Package Management**: OPKG configuration

### Development Additions
- Debugging tools (gdb, strace)
- Development headers and libraries
- Additional compilers and build tools
- Network diagnostic utilities

## Security
- **Users**: Root and non-root users with sudo access
- **Services**: Only essential services enabled
- **Firewall**: Default deny policy
- **Updates**: Signed package repositories

## Verification
```bash
# Check filesystem integrity
du -sh /

# Verify package versions
opkg list-installed

# Check for security updates
opkg list-upgradable

# Verify file permissions
find / -type f -perm -4000 -ls
```

## Recovery
1. Boot to recovery SD card
2. Mount root filesystem
3. Restore from backup or reflash
4. Run filesystem check (`fsck`)

## Performance
- Boot time to login prompt: < 10s
- Memory usage: ~100MB (idle)
- Storage requirements: 500MB+ (depending on features)

## Dependencies
- Kernel modules in `/lib/modules/$(uname -r)/`
- Shared libraries in `/lib/` and `/usr/lib/`
- Device nodes in `/dev/`
- Mount points in `/mnt/` and `/media/`
