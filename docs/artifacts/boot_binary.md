# Boot Binary (BOOT_DEBUG.BIN / BOOT.BIN)

## Description
The boot binary is the initial program that runs when the ZCU102 board powers on. It's responsible for the first stage of the boot process, including:
- Hardware initialization
- Loading and verifying subsequent boot stages
- Setting up the execution environment for the kernel

## File Details
- **File Extension**: `.BIN`
- **Type**: Binary
- **Generated By**: Xilinx Vitis / PetaLinux
- **Location**: `/boot/` on SD card or TFTP server root

## Versioning
- **Stable Release**: `X.Y.Z` (e.g., `2.1.0`)
- **Development Build**: `YYYY.MM-devN` (e.g., `2025.11-dev1`)
- **Hotfix**: Appends hotfix number (e.g., `2.1.1`)

## Security
- **Signature**: RSA-2048 signed
- **Checksum**: MD5 (for quick verification)
- **Verification**: Secure Boot enabled in production

## Dependencies
- Compatible with specific PMU Firmware versions
- Requires matching `system.dtb`/`devicetree.dtb`
- BootROM version must be >= 1.0.0

## Troubleshooting
- **Boot failure**: Verify checksum matches manifest
- **Hang at 0%**: Check UART connection, power supply
- **Secure boot failure**: Verify keys and signatures

## Related Artifacts
- `vmlinux`/`image.ub` (kernel image)
- `system.dtb` (device tree)
- `pmufw.elf` (PMU firmware)
